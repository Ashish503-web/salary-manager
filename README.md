# ACME Salary Manager

Web-based salary management software for ACME's HR team — replaces spreadsheets for managing ~10,000 employees' compensation across multiple countries, and answers questions about how the org pays people.

> Scaffolding in progress — see [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md) for the one-pager and [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for design notes. Full setup/run instructions will be filled in as the `server/` and `client/` apps are built out.
